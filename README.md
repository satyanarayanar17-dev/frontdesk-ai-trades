# FrontDesk AI

Build a polished, conversion-focused one-page website for a working-title startup called "FrontDesk AI for Trades".

Target customer: UK independent plumbing and heating companies.
Core promise: "Never lose another job because you couldn't answer the phone."

Offer:
- 24/7 AI phone receptionist for plumbers and heating engineers.
- Answers inbound calls naturally.
- Captures caller name, phone, postcode, issue, urgency, boiler/heating details where relevant.
- Distinguishes emergencies from routine enquiries.
- Collects preferred appointment times and sends structured lead summaries.
- Early-access managed service. Do not invent customers, testimonials, usage stats, logos, or badges.
- 7-day pilot: £0 setup. £249/month after pilot if they keep it. State that usage limits/fair-use terms apply.

Sections: hero, missed-call pain, 4-step workflow, clearly labelled fictional example call, features, pilot pricing, FAQ, final CTA, footer.
FAQ: Will customers know it is AI? Can it transfer urgent calls? Can I keep my existing number? What happens after the pilot? Does it replace my staff?

Primary CTA: Join the 7-day pilot.
Secondary CTA: Hear how it works.

Add a pilot interest form: business name, contact name, email, phone, website, city, approximate calls/week, notes. Validate fields and show a success state. If no real backend is connected, use a demo/local submission and make that limitation explicit in code, not prominent marketing copy.

Footer contact: satyanarayanareddy.tethala@gmail.com. Footer text: Early access — UK plumbing & heating.

Design: trustworthy UK trade-business aesthetic; clean premium; mobile-first; white/charcoal with one restrained accent; no futuristic neon; no stock-photo-heavy design.
SEO title: AI Receptionist for UK Plumbers & Heating Engineers.
SEO description focused on 24/7 call answering and missed-call recovery.
Build the complete site so it is credible enough to show real prospects today.
